# Sistema Integral de Gestión de Clientes, Servicios y Reservas 
## Descripción
El sistema permite registrar clientes, crear servicios especializados y gestionar reservas. Utiliza programación orientada a objetos, validaciones estrictas, manejo avanzado de excepciones y registro de eventos y errores en archivos de logs.
Los servicios son :
-Reserva de salas.
-Alquiler de equipos.
-Asesorias especializadas.
